# Viajes Chile

Landing page responsive orientada a la presentación de destinos turísticos y experiencias de viaje dentro de Chile.

El proyecto fue desarrollado como práctica de Frontend y combina estructura semántica, diseño responsive, componentes de Bootstrap e interacción mediante JavaScript.

---

## Descripción

Viajes Chile es una interfaz web enfocada en mostrar distintos destinos turísticos del país mediante una experiencia visual simple y adaptable a distintos dispositivos.

El sitio incluye un carrusel principal, una sección informativa, destinos destacados, formulario de contacto y elementos interactivos desarrollados con Bootstrap y JavaScript.

Este repositorio corresponde a una versión mejorada del proyecto original, incorporando una estructura visual más completa y uso de SCSS para la organización de estilos.

---

## Funcionalidades

- Navegación responsive

## Componentes principales

### Navegación

La barra de navegación utiliza Bootstrap y cambia dinámicamente su fondo al desplazarse por la página mediante JavaScript.

### Carrusel

La sección principal utiliza el componente Carousel de Bootstrap para mostrar distintos paisajes y experiencias relacionadas con turismo en Chile.

### Destinos destacados

Los destinos se presentan mediante tarjetas responsive que incluyen:

- Imagen
- Nombre del destino
- Descripción
- Precio referencial
- Información de vuelos

### Formulario de contacto

El sitio incorpora un formulario demostrativo con:

- Nombre
- Correo electrónico
- Mensaje
- Aceptación de términos y condiciones

El formulario utiliza JavaScript para controlar el evento de envío sin recargar la página.

### Elementos interactivos

Se implementaron componentes de Bootstrap y JavaScript como:

- Tooltips
- Modal
- Carrusel
- Navbar responsive
- Comportamiento dinámico al hacer scroll

---

## Diseño responsive

La interfaz está construida utilizando el sistema de grillas de Bootstrap para adaptarse a diferentes resoluciones.

Se utilizaron breakpoints y clases responsive para reorganizar el contenido según el tamaño de pantalla.
